# H2OROBOT

水中ロボットをスマートフォンから簡単に操作するためのアプリケーションと、ESP32向けプログラムを公開しています。

スマートフォンからESP32などへWi-Fi（UDP）で操作データを送信し、ロボットを遠隔操作できます。DualSenseなどのゲームコントローラーにも対応しています。

- 配布されたESP32 Dev Boardで動作確認済み

## ダウンロード

[最新版APKはこちら](https://github.com/enadorry/H2OROBOT/releases/latest)

## 主な機能

- スマートフォンからESP32へWi-Fi（UDP）で操作データを送信
- 画面上のUIからロボットを操作
- DualSenseなどのコントローラーをスマートフォンに接続して操作可能
- スティック、十字キー、各種ボタンによる移動・アーム・かごの操作

## ビルド方法

### Unity

Unityプロジェクトのパッケージは、リポジトリ内の以下のファイルです。

```text
H2Ov1.1.unitypackage
```

Unityは **6000.3.7f1** の使用を推奨します。

UnityPackageのインポート方法については、以下の記事などを参考にしてください。

- [UnityPackageのインポート方法](https://yttm-work.jp/unity_beginner/unity_beginner_0008.html#head_line_02)

外部パッケージとして読み込んだあと、Android向けにAPKをビルドしてください。

Androidビルドについては、以下の記事も参考になります。

- [UnityでAndroid向けにビルドする方法](https://shibuya24.info/entry/unity-build-android)

### Androidビルド時の注意

ビルド前に、Unityの以下の設定を確認してください。

**編集 → プレイヤー → 解像度と表示 → 自動回転が可能な向き**

ここで、以下のチェックを外してください。

- 縦向き
- 縦向き（逆）

その後、通常どおりAndroid向けにビルドしてください。

### Arduino / ESP32

ESP32側のプログラムは、以下のファイルです。

```text
kibann.ino.ino
```

ファイル名は少し特殊ですが、現在はこの名前で保存されています。

ESP32への書き込み方法については、Arduino IDEなどを使用してください。

## 使用方法

1. アプリを起動する前に、ESP32が出しているWi-Fiへスマートフォンを接続します。
2. ESP32側のSSIDとパスワードは、使用環境に合わせて設定して書き込んでください。
3. Wi-Fi接続後にアプリを起動します。
4. 画面上の操作UI、または接続したコントローラーからロボットを操作します。

> **重要**  
> アプリを先に起動してからESP32のWi-Fiへ接続すると、正常に反応しない場合があります。その場合はアプリを一度終了し、Wi-Fi接続後に再度起動してください。

## コントローラー操作

以下はDualSense使用時の操作例です。

| 操作 | 動作 |
| --- | --- |
| 左スティック | 前後左右の移動 |
| R1 | アームを上げる |
| R2 | アームを下げる |
| △ | かごを上げる |
| × | かごを下げる |
| 十字キー | 前後左右の移動 |
| 右スティック | 十字キーの上または下を押しているときに方角を調整 |

アプリ画面については、できるだけ直感的に操作できるUIを目指しています。

## トラブルシューティング

### ロボットが動かない

まず、スマートフォンとESP32がWi-Fiで正常に接続されているか確認してください。

接続済みでも動作しない場合は、以下を順番に試してください。

1. スマートフォンのモバイル通信をOFFにする
2. アプリを完全に終了する
3. ESP32のWi-Fiへ接続し直す
4. アプリを再起動する

Wi-Fiとモバイル通信が同時に有効になっている場合、端末側のルーティングによってUDP通信が意図したネットワークへ送信されないことがあります。

### アプリのビルド方法が分からない

Androidについては、ReleaseページからAPKを配布しています。

[最新版APKはこちら](https://github.com/enadorry/H2OROBOT/releases/latest)

iOS向けについては、現時点ではAndroid版ほど手順や配布環境が整っていません。今後、余裕があれば改善していく予定です。
